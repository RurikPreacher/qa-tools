QA Test File Generator

Generate a Windows CMD command to create a test file of a specified size, from 1 MB to 10 GB.

File parameters

1 MB – 10 GB (10,240 MiB)

The destination folder is created automatically if it does not exist. An existing file is not overwritten.

Ready-to-run command

Copy this into cmd.exe on Windows. The generated file contains zero bytes, not real document content.





Important: Changing an extension to .pdf, .xlsx, .zip, etc. does not produce a valid PDF, Excel workbook, ZIP archive, or other formatted document. This tool creates size-based dummy files for upload limits, storage, and negative testing.


All settings are stored only in this browser's localStorage. No file paths or entered values are uploaded to GitHub or a server.
